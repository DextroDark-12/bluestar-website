# Bluestar Granite & Marble — Website

## Project Structure

```
bluestar-website/
├── index.html         — Homepage with hero, categories, testimonials, CTA
├── products.html      — Stone collection with category filter and detail modal
├── contact.html       — Contact form, business info, and map placeholder
├── about.html         — Company story, team profiles, stats, and timeline
├── gallery.html       — Project gallery with category filter
├── css/
│   ├── style.css      — Variables, reset, typography, grid, utilities
│   ├── components.css — Navbar, footer, cards, buttons, hero, modal, forms
│   └── animations.css — Scroll-reveal, staggered delays, keyframes
├── js/
│   ├── main.js        — Navbar scroll, hamburger, scroll-reveal observer, smooth scroll
│   ├── products.js    — Category filter and stone detail modal
│   ├── contact.js     — Form validation on submit
│   └── gallery.js     — Gallery category filter
└── images/
    └── stones/        — Stone slab images (populated as needed)
```

## Pages

- **index.html** — Homepage featuring hero section, stone categories (granite/marble/quartzite), why-choose-us highlights, client testimonials, and CTA banner.
- **products.html** — Full stone collection with 12 varieties across 4 categories. Includes category filter buttons and a detail modal showing type, origin, finishes, and thickness.
- **contact.html** — Contact form with client-side validation, business address, phone, email, hours, and WhatsApp link.
- **about.html** — Company story and legacy, milestone stats bar, team member profiles, and a timeline from 2003 to present.
- **gallery.html** — Project gallery with 12 completed installations across kitchens, flooring, bathrooms, and exterior work. Category filter included.

## How to Run

Just open any `.html` file in a browser. No build step, no server, no dependencies required.
